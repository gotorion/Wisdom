## 一条记录怎么写

四部分，缺一不可：

| 部分 | 作用 |
|---|---|
| **一句话** | 用你自己的话提炼，能直接背下来 |
| **原话** | 两三句短引用，附链接，不整段搬运 |
| **为什么击中我** | 当时在纠结什么，为什么这句话对上了 |
| **后来用上了** | 什么时候真的按它做了，结果如何 |

最后一部分最容易被跳过，也最重要——它是"收藏"和"智慧"的区别。
